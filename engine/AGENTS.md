# postscore-ai Codex 使用规则

本项目是本地运行的 Python CLI 工具，用于视频后期评分、后期质检和 HTML/JSON 报告生成。

## 触发词

当用户输入以下任一关键词时，自动调用本项目：

- 后期评分
- 视频评分
- 后期检测
- 视频质检
- 剪辑评分
- 调色评分
- Amazon后期评分
- 抖音后期评分
- 小红书后期评分
- TikTok后期评分
- 深度后期评分
- 批量后期评分
- 多视频评分
- 文件夹评分

## 模式选择

- 已取消 `fast` 快检选项。
- 无论用户说“后期评分”“视频质检”还是“深度后期评分”，统一使用 `deep`。
- 如果用户说 Amazon，使用 `amazon_product`。
- 如果用户说抖音、小红书、TikTok、短视频，使用 `short_social`。
- 如果用户说品牌片、广告片、宣传片，使用 `brand_commercial`。

## 修改及复评

仅评分用下列命令。有修改方案或原改两版时，按评分 Skill 执行 revision-init / revision-plan、导出和两次相同预设的 review，最后用 revision-compare 交付成对 HTML/JSON。预测、改后自评、独立盲审、技术实测与发布状态分别列出。

## 默认命令

```bash
python -m postscore review "视频路径或链接" --mode deep --preset default --html --json
```

`--mode deep` 可省略，因为 deep 是唯一模式：

```bash
python -m postscore review "视频路径或链接" --html --json
```

## 单条与批量决策

- 用户只给 1 个本地视频或 1 个链接时，使用 `review`。
- 用户一次给多个链接、多个文件、文件夹路径，或明确说“批量/多个/文件夹”，使用 `batch`。
- `batch` 会始终为每条视频生成完整 HTML/JSON 报告，同时生成 `batch_index_*.html` 总览和 `batch_summary_*.csv` 汇总。
- 文件夹默认只扫描第一层视频文件；用户要求全量子目录时加 `--recursive`。
- 在线链接下载失败时，不要中断本地视频评分；批量总览中保留 failed 记录，并建议用户提供本地视频。

```bash
python -m postscore batch "文件夹路径" "视频路径" "公开视频链接" --preset short_social
```

## 速度策略

- 默认深度抽帧目标为 3 fps。
- 为了控制耗时，默认最多抽取约 360 张关键帧。
- 3 分钟以内视频通常能在 40 秒内完成，但具体取决于视频编码、磁盘、CPU 和下载速度。
- 如果需要更细检测，可手动设置 `--max-sampled-frames 0` 取消关键帧上限。

## Codex 返回格式

短视频采用至少 85 分的优化目标，按短视频评分 Skill 交付当前版本、差距、可执行的现有素材剪辑单和改后复评。仅在剪辑无法补足差距时给最小增补方案。常规检测返回：

- 分列原始后期技术分、按简报适用技术分、内容分、封面和发布状态。用户要求综合评价时，先用 brief 填写成片事实和真实入口，再用 review --editorial 生成内容、封面与技术报告。
- 等级
- 首页最多三项优先修改，全部确认的发布阻碍另列。技术告警按简报适用项判断。
- HTML 报告路径
- JSON 报告路径

批量任务还要返回：

- 成功数量 / 失败数量
- 批量总览 HTML 路径
- 批量 CSV 路径
- 每条视频的短名称、来源位置或原始链接、单独报告路径

## 约束

- 不要凭空编造视觉问题，所有问题必须来自检测指标或关键帧证据。
- 如果视频无法访问，提示用户提供本地路径。
- 如果用户授权 cookie，只用于当前下载任务；不要在日志、报告或回复里暴露 cookie/token。
- 如果依赖缺失，先运行：

```bash
python scripts/check_environment.py
```

然后告诉用户缺什么、如何修复。

## 报告验收清单

- `最终建议` 必须位于总评分下方、分项评分前方。
- `是否可发布` 必须作为主结论醒目展示。
- 关键帧指标必须中文化，不显示 Python 字典或英文键。
- 时间轴问题文字不得叠在 marker 上，说明文字放到独立事件区。
- Top 问题列表和关键帧证据区使用自适应多列布局，浏览器缩放时不挤压、不重叠。
- 横屏和竖屏截图都完整展示，不裁切主体。
